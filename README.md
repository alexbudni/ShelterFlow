# 🐾 ShelterFlow

Your task is to build a scalable, enterprise-ready dashboard for a cat shelter using React, TypeScript, and AI coding assistants.

## 🚀 Getting Started
1. Rename the `.env.example` file to `.env` and paste the API key.
2. Run `npm install`
3. Run `npm run dev` to start the application.
4. Run `npm run test` to start the testing environment.
5. Examine the `src/shared/api/apiClient.ts` file to understand how the data contracts and API requests work.
